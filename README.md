# 🏘️ Доступность жилья в России

Интерактивная визуализация данных о рынке недвижимости и доходах населения России за 2000–2025 годы.

## 📊 Что отображается

- **Сравнение цен** — сравнение динамики доходов и стоимости недвижимости
- **Аренда** — стоимость аренды 1-комнатной квартиры vs зарплата
- **Доступность** — сколько лет нужно копить на квартиру 54 м²
- **Доля аренды** — процент зарплаты, уходящий на аренду
- **Стоимость квартиры** — динамика цены типовой 1-комнатной квартиры (54 м²)
- **Сводный график** — нормализованное сравнение всех показателей

## 🚀 Технологии

- React + TypeScript
- Vite
- Tailwind CSS
- Recharts

## 📦 Запуск локально

```bash
npm install
npm run dev
```

## 🌐 Деплой на GitHub Pages

1. Соберите проект:
   ```bash
   npm run build
   ```

2. Запушьте папку `dist` в репозиторий

3. В настройках репозитория:
   - **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main**, папка: **/dist**
   - Нажмите **Save**

4. Сайт будет доступен по адресу: `https://<username>.github.io/<repo-name>/`

## 📈 Данные

Помесячные данные с января 2000 по декабрь 2025:
- Средняя зарплата
- Цена за м² недвижимости
- Аренда 1-комнатной квартиры
- Стоимость квартиры 54 м²
- Расчётные показатели доступности
